# Desafio Hardcore

## Sobre o projeto

Este desafio, proposto pelo professor de Fundamentos, tem como objetivo aplicar os conhecimentos adquiridos em aula sobre documentação e inglês técnico. Além disso, o projeto incentiva o desenvolvimento de habilidades de pesquisa, fundamentais para a resolução de problemas e o aprendizado de novas linguagens.  

## Estrutura

O projeto é composto por:

- Um arquivo HTML, com a temática do jogo Subnautica: Below Zero
- Um arquivo CSS, responsável pela estilização da página
- Um arquivo JavaScript, utilizado para implementar a funcionalidade de um botão com efeito hover
